# 不承诺屏幕阅读器对棋盘的完整游玩

V1 以 WCAG 2.2 AA 为目标，但明确把**屏幕阅读器对棋盘的完整游玩**排除在外：棋盘外的全部控件（设置、历史、预设、提示层）必须屏幕阅读器可操作，棋盘内只保证可聚焦的格子与状态播报（坐标 / 数字 / 标记态）。原因是完整 SR 网格游玩的实现与测试成本很高，且与低龄初学者的训练目标不重叠；把同一份预算投入键盘可操作、对比度、非颜色线索等通用可访问性，覆盖人群更广、收益更高。

## Considered Options

- **完整 SR 棋盘游玩**：拒绝——范围显著膨胀，收益与低龄训练目标不重叠。
- **棋盘完全不设无障碍**：拒绝——放弃可聚焦格与状态播报，会否认低视力 / 视障用户获取基本信息。
- **棋盘外 SR 可操作 + 棋盘内最小播报**（采纳）。

## Consequences

- 视障用户无法在 V1 独立完成对局；若将来需要，属于后续 effort，而非本规格的补充。
- 「定义 V1 验证策略与发布验收标准」中的辅助技术验收不包含棋盘内 SR 游玩。

# Triage 标签

工程 skills 使用五种标准 triage 角色。本文件定义它们在当前 issue tracker 中对应的实际标签。

| 标准角色 | Tracker 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交由 AFK agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当 skill 提到某种 triage 角色时，使用表中对应的 tracker 标签。若仓库以后调整标签命名，只需修改第二列。
